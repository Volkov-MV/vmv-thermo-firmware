# VMV-Thermo — выпуски прошивки

Здесь лежат только **подписанные файлы прошивки** контроллера электрокотла
VMV-Thermo. Исходного кода здесь нет.

## Каналы

- **Стабильный** — выпуски без отметки «Pre-release». Их получают все котлы.
- **Пилотный** — выпуски с отметкой «Pre-release». Их сначала получают
  испытательные котлы; через неделю-две без замечаний выпуск переходит в
  стабильный.

## Файл выпуска

Один файл `vmv-thermo-<версия>.bin`: образ прошивки и подпись. Котёл
устанавливает файл, только если подпись сделана ключом производителя, файл
предназначен для этой модели платы и версия новее установленной. Повреждённый
или чужой файл котёл отвергает и остаётся на прежней прошивке.

## Как обновить котёл

- **Сам:** котёл берёт файл отсюда сам. Запуск — с экрана котла, SMS
  «ОБНОВИ», из Home Assistant или ночью автоматически (в разработке; сейчас —
  консолью наладчика).
- **Без интернета у котла:** скачайте файл выпуска на телефон и загрузите его
  на странице котла (карточка «Прошивка», только для владельца).

После установки котёл перезагружается в тихий момент (нагрев прерывается
примерно на 30 секунд) и проверяет себя; если новая прошивка не справилась,
он сам возвращается к прежней.
